## Base Template

You are working in a minimal BitBot container.

### What's Included
- Essential tools: git, curl, node, Claude Code
- Basic BitBot hooks and skills
- No extra features

### Customization
To add features, edit `.devcontainer/devcontainer.json` and add:
- Packages via Dockerfile
- VS Code extensions
- DevContainer features

See the "Customizing DevContainers" section above for examples.
