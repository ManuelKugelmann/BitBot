# BitBot Test Workspace

This is a simple test workspace for BitBot testing.

## Purpose

Used for automated and manual testing of:
- Workspace initialization (`bitbot init`)
- Work mode (`bitbot work`)
- Config mode (`bitbot config`)
- VS Code integration (`bitbot vscode`)

## Usage

```bash
cd tests/test-workspace
../../bitbot init     # Initialize workspace
../../bitbot work     # Enter work mode
../../bitbot config   # Enter config mode
```
