
# AI Agent Research

This document summarizes research on AI agent tools that could be integrated with BitBot.

## Claude-Flow

**Link:** [https://github.com/ruvnet/claude-flow](https://github.com/ruvnet/claude-flow)

Claude-Flow is an enterprise-grade AI orchestration platform for Claude. It is designed to deploy intelligent multi-agent swarms and coordinate autonomous workflows.

### Key Features:

*   **ReasoningBank Memory:** Persistent SQLite storage with semantic search.
*   **Hive-Mind Intelligence:** Queen-led AI coordination.
*   **MCP Tools:** Over 100 MCP (Model Context Protocol) tools for automation.
*   **Dynamic Agent Architecture (DAA):** Self-organizing agents with fault tolerance.
*   **Advanced Hooks:** Automated workflows.
*   **GitHub Integration:** Repository management.
*   **Performance:** 84.8% SWE-Bench solve rate and 2-3ms query latency for semantic search.

## Open Code

**Link:** [https://github.com/sst/opencode](https://github.com/sst/opencode)

OpenCode is an open-source AI coding agent designed for the terminal.

### Key Features:

*   **Provider-Agnostic:** Supports various AI models like Anthropic, OpenAI, Google, and local models.
*   **LSP Support:** Out-of-the-box Language Server Protocol (LSP) support.
*   **TUI:** Terminal User Interface (TUI).
*   **Client/Server Architecture:** Allows for flexible usage, including remote control from different clients.
