## Preliminary Specifications

The `preliminary-specs/` directory contains early specifications generated by different AI assistants:

- **Claude_Specification**: Claude-generated specifications (comprehensive, 13 documents)
- **Copilot_Specification**: GitHub Copilot-generated specifications (11 documents)
- **Gemini_Specification**: Google Gemini-generated specifications (7 documents)

These preliminary specs were **condensed into the final specifications** in this directory through:
1. Cross-referencing all AI-generated specs
2. Identifying common patterns and best approaches
3. Resolving conflicts and inconsistencies
4. Refining through implementation experience
5. Documenting architectural decisions

## Usage

**Primary reference**: Use the final specifications (*.md files in this directory) as the authoritative source.

**Historical context**: Refer to preliminary-specs/ to understand:
- Evolution of design decisions
- Alternative approaches considered
- Rationale for final choices
- Cross-AI consensus on design patterns

## Development Guidelines

When implementing features:
1. **Follow final specifications** in this directory
2. Reference preliminary specs for context if needed
3. Document deviations in `00_DECISIONS.md`
4. Update specifications if implementation reveals better approaches

## Not Included in Release

All specification documents are excluded from release distributions. These are development artifacts only.
