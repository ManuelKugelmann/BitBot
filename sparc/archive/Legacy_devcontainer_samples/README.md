# Legacy DevContainer Samples

**Status**: Temporary reference - to be removed after BitBot templates are created

## Purpose

These sample devcontainer configurations are kept as **reference examples** until BitBot's own devcontainer templates are created in the `devcontainer-template/` directory.

## Contents

- **c++ sample/**: C++ development environment with devcontainer setup
- **unity3d sample/**: Unity3D C# development environment

## Usage

These are **NOT** for direct use with BitBot. They serve as:

✅ Reference examples for devcontainer structure
✅ Inspiration for BitBot template design
✅ Examples of multi-file devcontainer setups

## Removal Plan

These samples will be removed once:

1. ✅ BitBot devcontainer templates are created in `devcontainer-template/`
2. ✅ Templates are tested and working
3. ✅ Documentation references the new templates

## Why Restored

These were temporarily removed with the rest of the archive, but restored because BitBot's own templates haven't been created yet. Once proper BitBot templates exist, these legacy samples will be removed permanently.
